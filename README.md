# Open-cv-Tut
This repository contains beginner-friendly examples using OpenCV in Python.

🔹 Basics
Covers fundamental operations like:
Reading and displaying images
, Drawing shapes and text
, Handling windows and keyboard input (imshow, waitKey)


🎥 Video Capture
Learn how to:
Access webcam using VideoCapture
, Display live camera feed
, Record and save videos (VideoWriter)
, Handle real-time frame processing


🎨 Filters
Apply simple image transformations:
, Grayscale conversion
, Blurring (Gaussian, Average)
, Edge detection (Canny)
, Color transformations


💡 These examples are designed for quick learning and hands-on practice with real-time computer vision.
